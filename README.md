# Portafolio Personal — Geovan Yassil Pérez Encarnación

Este proyecto es un portafolio web creado como parte de la asignatura de Tecnologia y servicios de internet en la Universidad O&M.

## 📌 Descripción
El sitio web contiene tres secciones:
- **Inicio**: presentación, foto, redes sociales y datos personales.
- **Sobre mí**: información personal y habilidades.
- **Currículum**: formación académica, áreas de estudio y experiencia técnica.

Está desarrollado con:
- HTML5
- CSS3
- Estilo visual negro con detalles en rojo
- Responsive para dispositivos móviles
